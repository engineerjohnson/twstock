# 台股分析師 (TW Stock Analyst)

瀏覽器儀表板：國內外新聞 → 對台股影響、利多/利空判斷、技術面起漲篩選 (MA/MACD/KD/RSI/布林)、
三大法人 (外資/投信/自營) 突然大買、集保大戶週變化、基本面 (月營收/EPS/本益比)，以及 Claude AI 分析師解讀。

## 啟動
雙擊 `run.bat`（或 `python -m uvicorn app.server:app --port 8765`），瀏覽器開 http://127.0.0.1:8765

第一次啟動會在背景下載約 3 個月的上市/上櫃每日行情與法人資料 (約 5 分鐘)，畫面上方會顯示進度。

## 資料來源 (全部免費、免金鑰)
- 證交所 (TWSE) / 櫃買中心 (TPEx)：每日行情、三大法人買賣超、本益比、月營收、季 EPS、當日沖銷統計；證交所 MIS 盤中即時報價 (五檔/成交量)
- 富邦 e01 (DJ)：券商分點買賣超 (收盤後，供隔日沖判斷)
- 集保結算所 (TDCC)：股權分散表 (大戶持股)
- 鉅亨網 / Yahoo 股市 / 經濟日報 / Google News：新聞
- Yahoo Finance：美股、費半、台積電 ADR、VIX、匯率、亞股

## AI 分析師
按「AI 分析師解讀」會把最新新聞、國際行情、法人與量化篩選結果整理成提示詞，交給本機的
Claude Code CLI (`claude -p`) 產生報告；若無 CLI，可設定環境變數 `ANTHROPIC_API_KEY` 改走 API。

## 功能一覽
- **總覽**：國際市場 (美股/費半/台積電ADR/VIX/匯率/亞股，含 20 日走勢圖) → 台股影響判斷、大盤與三大法人、AI 分析師觀點、利多/利空新聞、推薦與突然大買。
- **新聞**：鉅亨網 / Yahoo / 經濟日報 / Google News，自動標記利多/利空、主題、相關個股與重點數字；可依盤前/盤後、分類、關鍵字篩選。摘要預設顯示 3 行、點一下展開全文。
- **語音播報**：新聞逐則朗讀「標題＋完整摘要」(內容再長也會切成短段完整唸完，不會中途靜音)、總覽一鍵播報重點；下方浮動列可暫停/下一則/點標題看全文。
- **推薦股**：技術 40% + 籌碼 30% + 基本 15% + 新聞 15% 綜合評分，展開可看理由與風險；**前一交易日成交量未達 1 萬張者不列入** (`config.REC_MIN_DAY_LOTS`)；可再依「近 20 日均量」門檻過濾；匯出 CSV。
- **技術面起漲**：15 種起漲訊號篩選（同樣僅列前一交易日成交量 ≥ 1 萬張者）+ **訊號勝率回測**（以本機歷史資料統計訊號出現後 1/3/5/10 日勝率，與基準比較）。
- **籌碼面**：**法人 / 外資 / 大戶 近一日買超總覽**（外資、投信、自營、三大法人合計任一買超或大戶週增即列出，依買超金額排序，並標示是誰在買）、三大法人合計買超金額排行、外資/投信/自營突然大買、連續買超、同步買超、金額排行、集保大戶 (≥400/≥1000 張) 週變化、融資減少、融券大增；會標示法人資料日期，若落後行情日會提醒。
- **排行/類股**：漲跌幅、成交張數/金額、量比、外資/投信買賣超金額、融資增加排行；產業類股漲跌熱力圖 (成交金額加權) 與龍頭股。
- **自選股**：★ 一鍵加入，盤中每 10 秒即時報價 (證交所 MIS)，可設價位提醒 (畫面 + 瀏覽器通知)、備註；匯出 CSV。
- **⚡ 當沖雷達** (本機版)：開盤 08:57 自動啟動，後端每 **5 秒**輪詢證交所 MIS 掃描前一日成交 **≥ 1 萬張** 的股票 (+ 自選股 + 高當沖比)，畫面每 5 秒刷新前 100 檔 (門檻可在畫面調整；熱度排序給成交張數多者加分)：
  振幅、跳空、時間量比 (累積量 ÷ 20 日均量 × 已開盤比例)、1 分量與爆量倍數、**外盤比 (買方主動) / 內盤比 (賣方主動)**、近 5 分淨主動買、相對 VWAP 均價、五檔掛單差、
  多空方向與訊號 (漲停/爆量/外盤強/站上均價/開高走低…)；點列展開 1 分 K + 每分鐘內外盤量柱；可開「強勢/弱勢警示」通知。
  內外盤以「每次輪詢的成交量增量」依成交價相對前一刻買/賣價歸類 (MIS 非逐筆，屬近似值)。
  **收盤後**自動抓證交所/櫃買當沖統計、候選股的券商分點進出 (富邦 e01)、加權指數、臺指期 (期交所日盤/夜盤) 與當日新聞，產生隔日 **做空候選**。
  規則是「成因型」而不是湊出來的：名單日大盤收漲 (全市場追價) + 個股漲 3～7% 非漲停 + 5 日漲幅 <10% (首次噴出、短線籌碼最多) → 隔日開高即出貨；
  漲停 / 漲幅過大 (需求未滿足)、5 日已漲 ≥10% (趨勢股)、大盤收跌日逆勢大漲 (真實買盤) 三種續強型態一律不列。隔日沖券商買超、外資賣超、買盤分散、當日上新聞只做加分與說明。
  全市場 66 日回測：名單 75% (前後半期各 75%)；隔日個股開高 0～3% 再執行 76%，再加 08:45 臺指期開高 >1% 時 81～86%；隔日大盤盤中轉強時降到 65%。
  弱勢股續跌做空與做多規則回測 (28 天 726 檔) 命中僅 44% / 38%，已降為觀察區。
  **開盤執行閘門**：08:30 起雷達顯示夜盤、08:45 期貨開盤跳空與盤中期貨/大盤；昨日空單在個股上標「開高 x%✔執行區 / 開高 >3%✘放棄 / 未開高✘放棄」，期貨或大盤開低、盤中翻強會警告縮手。
  **名單驗證**卡片每天自動對照隔日真實走勢 (全部 / 符合執行條件 / 執行 + 期貨開高)，並顯示每日大盤與期貨背景；每天收盤把全部 1 分 K 與期貨存到 `data/daytrade_bars/` 供日後盤中回測。
  推薦股 / 技術面 / 籌碼面名單上會標「⚡當沖偏空」提醒隔日沖倒貨風險；新聞盤前盤中每 15 分鐘自動更新，雷達個股標 📰。
- **個股K線**：日/週線切換，MA/布林/法人買賣超圖層開關，K 棒懸浮 OHLC，MACD、KD/RSI，法人 20 日、融資券 20 日、集保大戶、基本面、相關新聞；資料不足時自動向 Yahoo 補一年歷史。
- 所有表格表頭可點擊排序 (▼ 由大到小 / ▲ 由小到大)，欄位有白話說明；深色/淺色主題；`/` 快速搜尋。

## 雲端版 (GitHub Pages)
見 `deploy/DEPLOY_GITHUB.md`。GitHub Actions 每 30 分鐘 (06～23 點、避開整點) 自動更新新聞與國際行情，收盤後 (16:30 起) 若行情/法人尚未抓到就自動做完整更新；排程被 GitHub 延遲或略過時，下一次會自動補抓缺的交易日。
網頁開著不動也會每分鐘檢查雲端是否有新資料，有就自動重新載入。右上「更新新聞 / 更新行情」可用 GitHub Token 立刻觸發更新。

## 測試
```
python -m pytest tests -q
```
`tests/test_analysis.py`：技術指標對照 pandas、訊號偵測、籌碼/融資/大戶訊號、新聞分類、解析函式。
`tests/test_api.py`：以實際資料庫驗證每個 API 端點 (狀態碼、排序、過濾、結構、1 萬張成交量門檻、法人買超清單)。
`tests/test_cloud.py`：雲端排程 auto 模式判斷 (缺交易日就補抓) 與排程設定檢查。
`tests/test_daytrade.py`：當沖雷達內外盤分類、1 分 K/VWAP 累積、指標與多空方向、券商分點頁解析、隔日沖券商判斷、API 結構。

## Chrome 擴充功能 (選用)
`chrome-extension/` 是一個 Chrome 工具列彈出視窗，顯示今日推薦、外資/投信突然大買、利多/利空新聞，並可一鍵開啟儀表板。
安裝：Chrome 網址列輸入 `chrome://extensions` → 開啟右上「開發人員模式」→「載入未封裝項目」→ 選擇 `D:\台股分析\chrome-extension` 資料夾。
（需先用 run.bat 啟動本機伺服器）
